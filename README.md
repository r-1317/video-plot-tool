# plot_kdenlive.py

番号付きのリップシンク動画と、1 行に 1 セリフを書いた台本を、既存の Kdenlive プロジェクトに配置する Python スクリプトです。映像、動画に含まれる音声、編集可能な字幕タイトルを、それぞれ指定したトラックの先頭から番号順に隙間なく並べます。

## 必要なもの

- Python 3.10 以上
- `ffprobe`（[FFmpeg](https://ffmpeg.org/download.html) に付属し、コマンドとして実行できる状態）
- 映像・音声・字幕用の空トラックがある Kdenlive プロジェクト

Python の追加パッケージは不要です。提供されたサンプルをもとに Kdenlive のプロジェクト形式 1.1 で検証しています。他の形式のプロジェクトでは動作を確認していません。

## 使い方

動画ファイル名を `001_セリフ.mov`、`002_セリフ.mov` のように数字で始めます。台本は UTF-8 のテキストファイルとし、1 行目を 001、2 行目を 002 に対応させます。動画には映像と音声の両方が必要です。

Kdenlive で配置先の空トラックを作り、プロジェクトを保存します。必要ならトラック名と番号を確認してください。

```bash
python3 plot_kdenlive.py input.kdenlive --list-tracks
```

次の例では、映像を `V2`、音声を `A2`、字幕を `V4` に配置します。実際のプロジェクトに合わせて指定してください。

```bash
python3 plot_kdenlive.py input.kdenlive \
  --videos path/to/videos \
  --script path/to/dialogue.txt \
  --video-track V2 \
  --audio-track A2 \
  --subtitle-track V4 \
  --output result.kdenlive
```

出力ファイルを Kdenlive で開き、字幕の見た目や他の映像とのタイミングを確認してください。元のプロジェクトは上書きしません。出力先を省略すると、入力と同じフォルダーに `入力名-arranged.kdenlive` を作成します。既存の出力ファイルを置き換える場合は `--force` を付けます。

装飾の見本となる番号付き字幕タイトルが別の Kdenlive プロジェクトにある場合は、`--style-project path/to/style.kdenlive` を指定できます。最初の「字幕001」などからフォント、色、縁取り、位置を引き継ぎます。見本と出力先の解像度は同じにしてください。見本を省略すると、入力プロジェクト内の番号付き字幕タイトルを探し、なければ白文字・黒縁の既定スタイルを使います。見本はテキスト要素が 1 個のプレーンテキストのタイトルに対応しています。

`--dry-run` では入力を検証し、各クリップの開始時刻とフレーム数を表示します。ファイルは作成しません。台本の文字コードを変更するには `--encoding cp932` などを指定します。`ffprobe` が PATH にない場合は `--ffprobe path/to/ffprobe` で指定できます。全オプションは `python3 plot_kdenlive.py --help` で確認できます。

## オプション一覧

入力プロジェクトは位置引数 `project` として指定します。通常の配置では `--videos` と `--script` も必須です。`--list-tracks` ではこの 2 つを省略できます。

| 引数・オプション | 用途 | 既定値・省略時の動作 |
| --- | --- | --- |
| `project` | 配置先の空トラックを持つ `.kdenlive` ファイル | 必須の位置引数 |
| `--videos DIR` | 番号付き動画があるフォルダー | 通常の配置では必須 |
| `--script FILE` | 1 行目が 001 に対応する台本 | 通常の配置では必須 |
| `--style-project FILE` | 字幕の装飾を取得する見本プロジェクト | 入力プロジェクト内の番号付き字幕を使い、なければ既定スタイルを使う |
| `--output FILE`, `-o FILE` | 出力する `.kdenlive` ファイル | 入力と同じフォルダーの `入力名-arranged.kdenlive` |
| `--video-track TRACK` | 映像を配置するトラック | `立ち絵` |
| `--audio-track TRACK` | 音声を配置するトラック | `A2` |
| `--subtitle-track TRACK` | 字幕を配置するトラック | `字幕` |
| `--encoding ENCODING` | 台本の文字コード | `utf-8-sig`（UTF-8、BOM 可） |
| `--ffprobe COMMAND` | `ffprobe` の実行ファイル名またはパス | `ffprobe`（PATH から探す） |
| `--list-tracks` | トラック名・番号・ID・クリップ数を表示して終了 | 無効 |
| `--dry-run` | 入力を検証し、配置予定だけを表示する | 無効 |
| `--force` | 既存の出力ファイルを置き換える。入力ファイルは上書き不可 | 無効 |
| `--help`, `-h` | ヘルプを表示して終了 | 無効 |

`TRACK` はトラック名、`V2` / `A2` のような番号、または `--list-tracks` に表示される `tractor4` などの ID で指定できます。

## 配置時の扱い

- 対象フォルダー内の番号付き動画を数値順に読みます。フォルダーは再帰的に検索しません。番号のない動画は無視します。
- 台本の空行も行番号に含まれるため、空行はエラーです。動画の番号が重複している、001 からの連番に欠番がある、台本の行数と動画の本数が合わない場合もエラーにします。
- `ffprobe` で取得した映像の長さをプロジェクトのフレームレートに丸め、同じセリフの映像・音声・字幕を同じ位置と長さにします。映像と音声は Kdenlive の AVSplit グループでリンクします。
- 字幕はプロジェクトに埋め込むタイトルクリップです。台本の文字列をそのまま入れ、自動改行は追加しません。必要な改行は Kdenlive で編集してください。
- 配置先は空トラックに限ります。既存の他トラックのクリップと効果は保持します。背景や BGM の位置は変更しません。配置したセリフが元の尺を超える場合は、シーケンスの尺を延ばします。
- 素材ファイルは出力に含めず、絶対パスで参照します。素材を移動した場合は Kdenlive で参照先を修正してください。

## テスト

```bash
python3 -m unittest discover -s tests -v
```

テストは人工的な最小プロジェクトをその場で作成します。実際の動画素材や個人のプロジェクトファイルは不要です。Kdenlive の GUI での表示・再生は自動テストに含みません。
